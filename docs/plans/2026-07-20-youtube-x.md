# YouTube and X Reliability Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Download public YouTube Shorts and videos under ten minutes, and make public X video downloads resilient to X's browser checks.

**Architecture:** Extend URL classification with a YouTube platform and recognised public URL paths. Add a yt-dlp match filter that blocks only YouTube entries whose duration is unknown or exceeds 600 seconds, then add Chrome impersonation only to the X/Twitter extraction options. Keep the existing handler, temporary storage, size limit, thumbnails, and public-only model unchanged.

**Tech Stack:** Python 3.14, python-telegram-bot, yt-dlp, curl-cffi, pytest, Docker.

### Task 1: Recognise supported YouTube URLs

**Files:**
- Modify: `media_downloads/urls.py`
- Test: `tests/test_media_urls.py`

**Step 1: Write the failing tests**

Add parameterized accepted cases for a Shorts URL, a `youtube.com/watch?v=` URL, and a `youtu.be` URL. Add rejected cases for a channel URL and a watch URL without `v`.

**Step 2: Run the focused test to verify it fails**

Run: `make build_dev && docker run --rm --env-file .env comanditabot:latest python -m pytest -o addopts='' tests/test_media_urls.py -q`

Expected: the new YouTube URL cases fail because no `Platform.YOUTUBE` exists.

**Step 3: Implement minimal URL classification**

Add `YOUTUBE = "youtube"`, accept exact `youtube.com`/`m.youtube.com` Shorts and watch paths, and accept exact `youtu.be` IDs. Do not accept playlists, channels, HTTP, or look-alike hostnames.

**Step 4: Run the focused test to verify it passes**

Run the Task 1 test command again. Expected: all URL tests pass.

**Step 5: Commit**

```bash
git add media_downloads/urls.py tests/test_media_urls.py
git commit -m "feat: recognise public YouTube media links"
```

### Task 2: Reject long or undated YouTube videos before download

**Files:**
- Modify: `media_downloads/downloader.py`
- Test: `tests/test_media_downloader.py`

**Step 1: Write the failing tests**

Use the fake `YoutubeDL` to obtain the configured `match_filter`. Assert it accepts a YouTube entry at 600 seconds and rejects entries above 600 seconds or without duration, while not filtering an Instagram entry.

**Step 2: Run the focused test to verify it fails**

Run: `make build_dev && docker run --rm --env-file .env comanditabot:latest python -m pytest -o addopts='' tests/test_media_downloader.py -q`

Expected: the duration-filter assertions fail because no filter is configured.

**Step 3: Implement the minimal filter**

Define `YOUTUBE_MAX_DURATION_SECONDS = 600`. Add a yt-dlp `match_filter` that applies only when the source URL is YouTube and returns an explanatory rejection string for an unknown or over-limit duration. Log the rejection through yt-dlp's normal `DownloadError` path; leave all non-YouTube formats unchanged.

**Step 4: Run the focused test to verify it passes**

Run the Task 2 test command again. Expected: all downloader tests pass.

**Step 5: Commit**

```bash

```
